# 🛒 E-Commerce Customer Churn Prediction

An end-to-end Machine Learning project that predicts whether an e-commerce customer is likely to churn based on customer profile, purchasing behaviour, engagement and financial information.

## 🚀 Live Dashboard

Dashboard link will be added after Streamlit deployment.

## 📌 Project Overview

Customer churn is an important business problem in e-commerce.

This project uses Machine Learning to identify customers who are likely to churn and provides a Streamlit dashboard for real-time churn prediction.

## 🎯 Objective

The objective of this project is to:

- Analyse customer behaviour
- Clean and preprocess customer data
- Perform Exploratory Data Analysis (EDA)
- Identify important factors related to churn
- Train Machine Learning classification models
- Predict customer churn probability
- Provide actionable customer retention insights

## 🤖 Machine Learning

**Problem Type:** Binary Classification

**Target Variable:** `Churned`

- `0` → Customer likely to stay
- `1` → Customer likely to churn

**Final Model:** XGBoost Classifier

## 📊 Dataset

The dataset contains customer demographic, purchasing, engagement and financial information.

Important features include:

- Age
- Gender
- Country
- City
- Membership Years
- Total Purchases
- Average Order Value
- Days Since Last Purchase
- Cart Abandonment Rate
- Wishlist Items
- Returns Rate
- Discount Usage Rate
- Login Frequency
- Session Duration
- Pages Per Session
- Mobile App Usage
- Social Media Engagement
- Email Open Rate
- Product Reviews
- Customer Service Calls
- Payment Method Diversity
- Lifetime Value
- Credit Balance
- Signup Quarter
